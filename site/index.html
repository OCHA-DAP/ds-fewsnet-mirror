One row per geographic unit × scenario per collection round (Food Security Outlooks ~3×/year, plus Outlook Updates and Key Message Updates). The reporting date is the collection round; "valid from/to" is the projection window the phase applies to — a later round's current overlaps an earlier round's projection. Units are FEWS NET's own geography (FNIDs — livelihood-zone × admin intersections, admin units, IDP camps), not COD p-coded admin units, and there are no population- in-phase figures: FEWS NET classifies areas. FEWS NET's analysis is IPC-compatible but is not the IPC/CH consensus — the two can disagree; for the consensus product see the IPC/CH mirror.
